# Security policy

Bunyan is a static website and a set of documents. It has no server and no accounts, and it stores nothing except the language and theme you choose, in your own browser.

## Reporting a problem

If you find a security problem in the website, such as a way to run script through a shared link, report it privately through [GitHub private vulnerability reporting](https://github.com/SiteQ8/Bunyan/security) instead of opening a public issue.

Errors in the guidance itself, such as a wrong mapping or an outdated reference, are not security problems. Open an ordinary issue for them.
